# مقرأة هدايات الحفّاظ

نظام إدارة مقرأة لحفظ القرآن الكريم — رصد يومي للمهام، ترتيب تنافسي، وإدارة دفعات.

> **الحالة:** هيكل أساسي. النسخة العاملة حالياً مبنية على Google Apps Script وتخدم مستخدمين فعليين؛ هذا المستودع هو إعادة بنائها على Cloudflare Workers + D1. الأفكار والمنطق منقولان، والتنفيذ قيد الإكمال.

---

## الفكرة

الطالب يسجّل مرّة واحدة، ثم يرصد إنجازه اليومي عبر قائمة مهام (سبع افتراضياً، قابلة للتغيير حسب المسار). النظام يحسب نسبة الإنجاز، ويرتّب الطلاب على مستوى الدفعة وعلى المستوى العام، ويرسل رسالة تحفيزية مشروطة بالأداء.

المشرف يوافق على طلبات التسجيل، ويتابع المتعثّرين والمتصدّرين، ويؤرشف الدفعة عند انتهائها — فيستخرج النظام من الأرشيف قائمة **مرشّحين** يصلحون للانضمام إلى الدفعة التالية.

---

## المفاهيم الأساسية

| المفهوم | الشرح |
|---|---|
| **الرصد اليومي** | قائمة مهام يحدّدها الطالب؛ النسبة = المنجز ÷ الإجمالي |
| **يوم الرصد** | الرصد ينتمي ليوم محدّد وله موعد نهائي — ليس وقت الإرسال |
| **أيام التأخر** | الفرق بين آخر نشاط ويوم الرصد الحالي؛ يحدّد المتعثّرين |
| **الدفعة** | مجموعة طلاب تبدأ وتنتهي معاً؛ تُؤرشف ولا تُحذف |
| **المرشّح** | طالب من دفعة مؤرشفة أثبت التزاماً، يُرشَّح للعودة |
| **المسار** | خطة حفظ تحدّد عدد المهام اليومية |
| **الرسالة التحفيزية** | تُختار حسب نسبة اليوم وجنس الطالب، وتُهيَّأ من لوحة الإعدادات |

## البنية

```
Cloudflare Worker (Hono)
├── /api/auth/*       تسجيل ودخول الطالب والمشرف
├── /api/student/*    الرصد، الإحصاءات، الترتيب
├── /api/admin/*      الطلاب، الطلبات، الإعدادات
├── /api/batches/*    الأرشفة ودورة حياة الدفعة
└── /api/candidates/* الترشيح والاستعادة
         │
         └── D1 (SQLite) — انظر schema.sql
```

**لماذا الانتقال عن Apps Script:** التجميع كان يقرأ الورقة كاملة في الذاكرة ويتدهور مع نمو البيانات، والبحث عن طالب بالجوال كان مسحاً خطّياً، والأرشفة كانت تنسخ البيانات إلى أوراق جديدة. في D1 تصبح هذه استعلامات مفهرسة، والأرشفة تغيير حالة.

## التشغيل محلياً

```bash
npm install
npx wrangler d1 create hedayat-db          # ثم انقل معرّف القاعدة إلى wrangler.toml
npx wrangler d1 execute hedayat-db --local --file=./schema.sql
npx wrangler d1 execute hedayat-db --local --file=./seed.sql
npm run dev
```

للنشر:

```bash
npx wrangler d1 execute hedayat-db --remote --file=./schema.sql
npx wrangler deploy
```
